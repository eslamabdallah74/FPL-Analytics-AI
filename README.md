# ⚽ FPL Analytics & AI Decision Hub (100% Client-Side React)

A modern, high-performance Fantasy Premier League (FPL) analytics platform built with **React**, **TypeScript**, **TailwindCSS**, and **Vite**.

Designed for 1-click **Vercel** deployment with **zero backend server requirements**.

---

## ⚡ Tech Stack & Architecture

- **Frontend**: React 18, TypeScript, Vite, TailwindCSS, Lucide Icons
- **Analytics Engine**: Pure client-side TypeScript calculations for Form, FDR, xP, Value, Transfer Scores, Captain Scores, Team Optimization, and Player Verdicts.
- **FPL API Integration**: Direct client-side fetching with automatic browser CORS proxies (`corsproxy.io`, `allorigins.win`) for live Premier League data & Manager Team Sync.
- **Deployment**: Ready for Vercel, Netlify, Cloudflare Pages, or GitHub Pages.

---

## 🚀 Quick Start (Local Development)

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev
```

Visit [http://localhost:5173](http://localhost:5173) in your browser.

---

## 🌐 Deploying to Vercel

1. Push this repository to GitHub.
2. Go to [Vercel Dashboard](https://vercel.com/new).
3. Import `eslamabdallah74/FPL-Analytics-AI`.
4. Click **Deploy**! No environment variables or custom build settings required.

---

## 🌟 Key Features

- **🏆 "Build My Best Team" Engine**: AI squad builder based on budget, formation, locked/excluded players.
- **📋 Squad Analyzer**: Load any public FPL Team ID to view live pitch lineup, captain recommendations, bench swap alerts, and buy/sell advice.
- **🔄 AR / EN Bilingual Support**: Full English & Arabic UI with right-to-left layout and seamless toggle.
- **⚔️ Player Comparison**: Side-by-side metric comparison matrix with automated verdicts.
- **🎯 Transfers & Captaincy**: Live ranking algorithms for transfer targets, captaincy candidates, and differentials.
